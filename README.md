# مدقق · الورديات

تطبيق ويب لاستلام وتسليم ورديات الكاشير في المحلات اللي بتديرها مدقق.

- الكاشير: يدخل باسمه ورقم سري، يستلم، يسجل المصروفات والإيرادات والتحويلات، ويسلّم.
- المحاسب: يراجع الوردية، يكتب المبيعات، يطلع العجز أو الزيادة، ويقفل.
- المدير والأونر: تقارير يومية وشهرية.

مبني بـ React + Vite + Firebase (Auth + Firestore). قواعد الحماية في `firestore.rules`.

```
npm install
npm run dev      # تشغيل محلي
npm run build    # نسخة النشر في dist/
```
